# TC-01 Проверка сортировки товаров в категории

## Цель

Проверить корректность сортировки товаров по имени и цене в категории.

## Предусловия

* Открыт сайт Automation Test Store
* Пользователь находится на главной странице

## Шаги и ожидаемый результат

| Шаг                                                            | Ожидаемый результат                                        |
| -------------------------------------------------------------- |------------------------------------------------------------|
| Открыть первую доступную категорию товаров.                    | Открыта страница категории товаров.                    |
| Проверить наличие сортировки и количества товаров в категории. | На странице есть сортировка, отображается не менее 4 товаров. |
| Выбрать сортировку `Name A - Z`.                               | Товары отсортированы по имени в порядке возрастания.       |
| Получить список названий товаров.                              | Список названий доступен для проверки порядка сортировки.  |
| Выбрать сортировку `Name Z - A`.                               | Товары отсортированы по имени в порядке убывания.          |
| Получить список названий товаров.                              | Список названий доступен для проверки порядка сортировки.  |
| Выбрать сортировку `Price Low > High`.                         | Товары отсортированы по цене в порядке возрастания.        |
| Получить список цен товаров.                                   | Список цен доступен для проверки порядка сортировки.       |
| Выбрать сортировку `Price High > Low`.                         | Товары отсортированы по цене в порядке убывания.           |
| Получить список цен товаров.                                   | Список цен доступен для проверки порядка сортировки.       |

# TC-02 Проверка поиска и корзины (shirt)

## Цель

Проверить работу поиска, добавление товаров в корзину и правильного расчета суммы.

## Предусловия

* Открыт сайт Automation Test Store

## Шаги и ожидаемый результат

| Шаг                                                                                    | Ожидаемый результат                                                 |
| -------------------------------------------------------------------------------------- |---------------------------------------------------------------------|
| Ввести в поиск значение `shirt` и выполнить поиск.                                     | Отображается страница поисковой выдачи.                             |
| Проверить результаты поиска.                                                           | На странице есть сортировка, найдено не менее 3 товаров.            |
| Отсортировать товары по `Name A - Z`.                                                  | Товары в выдаче отсортированы по имени в порядке возрастания.       |
| Открыть второй товар из списка, доступный для добавления в корзину.                    | Открыта карточка товара.                                            |
| При необходимости выбрать обязательные параметры товара и задать случайное количество. | Товар подготовлен для добавления в корзину.                         |
| Добавить товар в корзину.                                                              | Товар добавлен в корзину.                                           |
| Повторно выполнить поиск `shirt` и отсортировать по `Name A - Z`.                      | Отображается актуальная поисковая выдача, отсортированная по имени. |
| Открыть третий товар из списка, доступный для добавления в корзину.                    | Открыта карточка товара.                                            |
| При необходимости выбрать обязательные параметры товара и задать случайное количество. | Товар подготовлен для добавления в корзину.                         |
| Добавить товар в корзину.                                                              | Товар добавлен в корзину.                                           |
| Перейти в корзину.                                                                     | Открыть страницу корзины.                                           |
| Проверить содержимое корзины.                                                          | В корзине отображаются 2 товара.                                    |
| Найти самый дешевый товар в корзине.                                                   | Определён товар с минимальной ценой.                                |
| Увеличить количество самого дешевого товара в 2 раза и обновить корзину.               | Количество самого дешевого товара обновлено.                        |
| Рассчитать ожидаемый `Sub-Total` и сравнить с фактическим значением.                   | Фактический `Sub-Total` совпадает с ожидаемым значением.            |


# TC-03 Проверка корзины (5 случайных товаров)

## Цель

Проверить добавление случайных товаров, удаление чётных по счёту товаров и корректность итоговой суммы.

## Предусловия

* Открыт сайт Automation Test Store

## Шаги

| Шаг                                                                                    | Ожидаемый результат                                      |
| -------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| Получить список товаров на главной странице.                                           | Список товаров на главной странице успешно отображается. |
| Проверить количество товаров на главной странице.                                      | Доступно не менее 5 товаров.                             |
| Случайным образом выбрать товары с главной страницы.                                   | Подготовлен набор товаров для добавления в корзину.      |
| Последовательно открывать товары и проверять, что они доступны для добавления.         | Для добавления выбираются только доступные товары.       |
| При необходимости выбрать обязательные параметры товара и задать случайное количество. | Товар подготовлен для добавления в корзину.              |
| Добавлять товары в корзину, пока не будет добавлено 5 товаров.                         | В корзину успешно добавлено 5 товаров.                   |
| Перейти в корзину.                                                                     | Открыта страница корзины.                                |
| Проверить содержимое корзины.                                                          | В корзине отображаются 5 товаров.                        |
| Удалить товары с чётными порядковыми номерами.                                         | Из корзины удалены все чётные по порядку товары.         |
| Проверить количество оставшихся товаров.                                               | В корзине осталось 3 товара.                             |
| Рассчитать ожидаемый `Sub-Total` и сравнить с фактическим значением.                   | Фактический `Sub-Total` совпадает с ожидаемым значением. |
