# TC-01 Проверка сортировки товаров в категории

## Цель

Проверить корректность сортировки товаров по имени и цене в категории.

## Предусловия

* Открыт сайт Automation Test Store
* Пользователь находится на главной странице

## Шаги

1. Открыть первую доступную категорию товаров.
2. Убедиться, что в категории:

    * есть сортировка
    * отображается не менее 4 товаров
3. Выбрать сортировку `Name A - Z`.
4. Получить список названий товаров.
5. Проверить, что список отсортирован по возрастанию.
6. Выбрать сортировку `Name Z - A`.
7. Проверить, что список отсортирован по убыванию.
8. Выбрать сортировку `Price Low > High`.
9. Получить список цен товаров.
10. Проверить сортировку по возрастанию.
11. Выбрать сортировку `Price High > Low`.
12. Проверить сортировку по убыванию.

## Ожидаемый результат

* Сортировка работает корректно во всех направлениях.

# TC-02 Проверка поиска и корзины (shirt)

## Цель

Проверить работу поиска, добавление товаров в корзину и правильного расчета суммы.

## Предусловия

* Открыт сайт Automation Test Store

## Шаги

1. Ввести в поиск значение `shirt`.
2. Выполнить поиск.
3. Убедиться, что:

    * есть сортировка
    * найдено не менее 3 товаров
4. Отсортировать товары по `Name A - Z`.
5. Открыть второй товар из списка (если товар доступен для добавления).
6. Задать случайное количество товара.
7. Добавить товар в корзину.
8. Повторить поиск `shirt`.
9. Отсортировать по `Name A - Z`.
10. Открыть третий товар (если доступен).
11. Задать случайное количество.
12. Добавить товар в корзину.
13. Перейти в корзину.
14. Проверить, что в корзине 2 товара.
15. Найти самый дешевый товар.
16. Увеличить его количество в 2 раза.
17. Обновить корзину.
18. Сравнить с фактическим Sub-Total.

## Ожидаемый результат

* Количество самого дешевого товара увеличено
* Итоговая сумма рассчитана корректно

# TC-03 Проверка корзины (5 случайных товаров)

## Цель

Проверить добавление случайных товаров, удаление чётных по счёту товаров и корректность итоговой суммы.

## Предусловия

* Открыт сайт Automation Test Store

## Шаги

1. Получить список товаров на главной странице.
2. Убедиться, что доступно не менее 5 товаров.
3. Случайным образом выбрать товары.
4. Добавлять товары в корзину, пока не будет добавлено 5 доступных товаров:

    * открыть товар
    * проверить, что он не Out of Stock
    * задать случайное количество
    * добавить в корзину
5. Перейти в корзину.
6. Проверить, что в корзине 5 товаров.
7. Удалить товары с четными индексами.
8. Проверить, что осталось 3 товара.
9. Рассчитать Sub-Total и сравнить с фактическим.

## Ожидаемый результат

* В корзине остается 3 товара
* Итоговая сумма совпадает с ожидаемой
